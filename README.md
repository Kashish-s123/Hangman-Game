# 📈 Stock Portfolio Tracker

A Python-based application for tracking stock investments and calculating the total value of a stock portfolio.

## 📌 Project Overview

The **Stock Portfolio Tracker** is a beginner-friendly Python project designed to help users manage and monitor their stock investments. It demonstrates how Python can be used to store investment details, calculate portfolio value, and organize financial data.

## ✨ Features

- 📊 Track stock investment details
- 💰 Calculate total portfolio value
- 📈 Organize stock holdings
- 🐍 Simple Python implementation
- 🎯 Beginner-friendly project for learning programming and financial calculations

## 🚀 Getting Started

### Prerequisites

- Python 3 installed on your computer
- A code editor, such as Visual Studio Code

### 1. Clone the Repository

```bash
git clone https://github.com/Kashish-s123/Stock-Portfolio-Tracker.git
```

### 2. Open the Project Folder

```bash
cd Stock-Portfolio-Tracker
```

### 3. Run the Application

```bash
python Stock_Portfolio_Tracker.py
```

If your computer uses `python3`, run:

```bash
python3 Stock_Portfolio_Tracker.py
```
